# Соответствие исходным 18 слайдам и таблицам задания

| Слайды | Учтено в прототипе |
|---|---|
| 1–3: цель, бизнес роль и структура результата | API выдаёт атрибут, значение, уверенность, источник и статус; интерфейс показывает их рядом с карточкой. |
| 4: масштаб, длинный хвост, нормализация | Схема строится из 6 963 категорий; нормализуются основные единицы и синонимы, редкие значения сохраняются осторожно. |
| 5: per-attribute P/R/F1, coverage, трафик, human gold | `scripts/evaluate.js` считает срезы; встроен размеченный ассистентом пример 30 SKU для воспроизведения расчёта. Независимый human gold ещё не получен. Клики используются только как прокси. |
| 6–7: эволюция и базлайн правил | `src/extractor.js` и `src/catalog-extractor.js` реализуют правила/словари как дешёвый первый этап. |
| 8–9: NER и дообученный энкодер | Рассмотрены как следующий этап после BIO/gold-разметки; в архиве такой разметки нет. Вместо фиктивного NER проведён измеримый silver-эксперимент с ML цвета. |
| 10: изображение | Не используется по прямому ограничению задания. |
| 11–12: LLM, сравнение и гибрид | На VM LLM включена по умолчанию в обычном пути веб-интерфейса и API через `LLM_AUTO_REVIEW=1`; вызывается только для пропусков и спорных полей, проверяет цитату и не меняет принятые правилами значения. Та же ветка доступна в небольшом пакете `scripts/predict.js` с лимитом вызовов; потоковая выгрузка миллиона SKU остаётся на правилах из-за стоимости. Фактические вызовы и ограничения зафиксированы в `reports/vm-validation-2026-10-22.md`. |
| 13–14: end-to-end и обратная связь | Схема → извлечение → нормализация → проверка → JSON; `review` и `missing` предназначены для ручной разметки и обновления правил. |
| 15: риски | Описаны в `docs/analysis.md` и слайде 7 финальной презентации. |
| 16–17: задание и данные | Реальный архив проанализирован; отсутствующий официальный список обязательных атрибутов и human gold не подменены выдуманными. |
| 18: шесть артефактов | Перечень и пути в README. |

Таблица подходов со скриншота 2 отражена в слайде 4 финальной презентации: правила, ML и LLM показаны вместе с качеством на хвосте, стоимостью и cold-start. Таблица метрик со скриншота 3 отражена в EDA, evaluator и слайде 6: precision/recall/F1 по атрибутам, coverage, трафик и человеческий gold по категориям.
