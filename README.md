# М.Видео — ИИ для заполнения характеристик товаров

Продуктовый бриф для чекпоинта хакатона 15 октября 2026 года. Проект извлекает атрибуты из названия, описания и полей продавца, приводит значения к единому виду и показывает источник, метод, уверенность и статус каждого значения. Изображения не используются.

**[Открыть продуктовый бриф (PDF)](product-brief-checkpoint.pdf)** — 8 слайдов, ответы на пять вопросов чекпоинта и скриншоты работающего прототипа.

## Какую задачу решаем

Незаполненные характеристики мешают товару попадать в фильтры и сравнение, а ошибочные значения искажают каталог. Основной пользователь — специалист каталога или модератор, который проверяет спорные атрибуты. Продавец может увидеть результат при подготовке карточки; покупатель получает пользу через более полный поиск.

## Что уже работает

- Локальный браузерный интерфейс и JSON API для одной карточки: название, описание, поля продавца и необязательная категория.
- Правила и словари для явных полей, нормализации распространённых цветов, единиц измерения и отдельных систем размеров.
- Для каждого атрибута выводятся значение, цитата из карточки, поле-источник, метод, эвристическая уверенность и статус `accepted`, `review` или `missing`.
- В интерфейсе доступно 110 SKU из предоставленного архива; подготовлен пакет JSON-предсказаний для 1 177 200 текстовых SKU.
- Прототип и API проверены на смартфоне, ноутбуке, чайнике, футболке и контрольных карточках с пропусками и конфликтами; 6 из 6 автоматических тестов правил проходят.

Архив содержит 1 177 200 текстовых SKU, 546 069 предложений с параметрами каталога и 30 991 350 строк кликов запрос–SKU. В таксономии 6 963 категории. Эти числа описывают данные и масштаб обработки, а не качество извлечения.

## Стадия и ограничения

Это работающий прототип, а не завершённая продуктовая оценка. Независимого human gold и официального списка обязательных полей для всех категорий в архиве нет. Поэтому precision, recall и F1 по атрибутам пока не заявляются. Клики без показов и событий фильтров не позволяют оценить CTR или влияние на GMV. Экспериментальная ML-модель цвета не развёрнута в основном потоке; LLM-адаптер предусмотрен, но не настроен. Русские и английские варианты типовых значений поддерживаются правилами; китайская карточка без структурированных полей остаётся ограничением.

Следующий этап — получить независимую разметку и официальный список полей, оценить качество по каждому атрибуту, редким категориям и небольшим продавцам, затем настроить пороги публикации и ручной проверки. Ключевая мера против ложных атрибутов уже действует: спорное или неподтверждённое значение не принимается автоматически.

На этом публичном чекпоинте размещены README и PDF-бриф. Исходный архив карточек и производные выгрузки в публичный репозиторий не загружаются.
