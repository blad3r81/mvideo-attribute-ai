## Что остаётся открытым

Независимый gold-набор и официальный перечень обязательных полей для всех категорий не предоставлены. Поэтому нельзя честно заявить gold precision/recall/F1, калиброванную вероятность уверенности и одинаковое качество для редких категорий и небольших продавцов. Текущая обработка длинного хвоста отправляет неизвестные значения на ручную проверку и не публикует их автоматически; оценка качества этого маршрута появится только после разметки. Публичное демо работает без авторизации сознательно; для закрытой интеграции предусмотрен отдельный режим с токеном. Лимит LLM хранится в памяти одного процесса; при масштабировании нужен общий счётчик.

2. Бэкендеру: проверить закрытый режим API, ограничения входа, таймауты и поведение при падении LLM. Отдельно оценить общий лимит обращений к модели для нескольких экземпляров сервиса.
3. Участнику по данным: составить небольшой независимый gold-набор по смартфонам, ноутбукам и редким категориям, включая разных продавцов, затем прогнать `scripts/evaluate.js` и отметить ошибки нормализации.

Основной код находится в командном Gitea в ветке `main`. Перед изменениями создавайте отдельную ветку и согласуйте объединение, чтобы автопроверка видела стабильный `main`.
