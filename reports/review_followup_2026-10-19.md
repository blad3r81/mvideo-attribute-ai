# Повторный аудит по восьми замечаниям прогона

Оценки относятся к утреннему коммиту. Изменения ниже сделаны после него и ещё не получили оценку платформы. Рост баллов и место в таблице не гарантированы.

| Критерий | Что проверено и изменено | Что остаётся |
|---|---|---|
| Обязательные сценарии | Тесты проверяют смартфон, ноутбук, новую категорию со схемой, конфликт, диапазон, отсутствие значения, двуязычные единицы и размеры. | Официальной матрицы обязательных полей для всех категорий нет в архиве. Полное покрытие подтвердить нельзя. |
| Ограничения кейса | Вход только текстовый; принятые значения имеют цитату из поля; неизвестное значение не превращается в факт. Демонстрационные SKU теперь не зашиты в универсальную проверку запуска. | Правила для смартфона и ноутбука основаны на примерах ТЗ; другие категории требуют официальной схемы. |
| Сквозной сценарий | Универсальная проверка `node scripts/smoke.js` берёт доступные демо-карточки и отдельную текстовую карточку, сверяет API с извлекателем, цитаты и отклонение неверного ввода. | Проверка текущей нагрузки не доказывает работу на промышленном потоке. |
| Воспроизводимость | `node scripts/check_setup.js` проверяет версию Node, порт, JSON схемы и демо-данные до запуска. README задаёт запуск и затем проверку. | Полная пакетная выгрузка требует исходного архива и Python-зависимостей. |
| Архитектура | Сквозная проверка отделена от известных SKU архива; пути схемы и демо задаются окружением. Чтения JSON при импорте уже устранены в предыдущем коммите. | Большая пакетная обработка по-прежнему использует подготовленный формат архива; универсальный импорт произвольных CSV не заявлен. |
| Ошибки и сбои | Таймауты LLM и API уже есть; новая проверка обнаруживает неверную конфигурацию до запуска. UI сообщает о не-JSON ответе шлюза и неполном JSON. Архив и частичный пакетный вывод проверены тестами. | Короткий стресс-тест не равен длительному испытанию; распределённого журнала и общей квоты между экземплярами нет. |
| Сценарий пользователя | Ошибки поля ввода, соединения и шлюза показаны рядом с формой. После фильтрации таблицы ранее отмеченное решение модератора остаётся видимым. | Ручное решение пока скачивается файлом и не записывается автоматически в каталог. |
| Подача результата | Статусы и эвристическая уверенность объяснены в UI; источник показан понятным названием, JSON сохранён в модальном окне. | Калибровка числовой уверенности возможна только по независимому human gold. |

Локально прошли 38 тестов Node. Универсальная сквозная проверка прошла четыре доступные демо-карточки, отдельную текстовую карточку и три неверных запроса. Результат на VM проверяется отдельно после переноса изменений.

На VM после пересборки прошла такая же сквозная проверка: четыре демо-карточки, одна текстовая карточка и три ошибочных запроса.
